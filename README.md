# Job Portal - React

A responsive Job Portal UI built using React.js.

## 🚀 Features

- Reusable Job Card Component
- Dynamic job data using JavaScript arrays
- React Props
- Array map() for rendering
- Save button with Lucide React icon
- Apply Now button
- Hover effects
- Responsive card layout

## 🛠️ Tech Stack

- React.js
- JavaScript
- HTML
- CSS
- Lucide React
- Vite

## 📸 Project Preview

Job listing cards with company, job title, experience level, salary, location and apply button.
